Control

Bedienelemente und Signal-Router: Knöpfe, Buttons, Schalter und Multiplexer, mit denen man Werte einstellt oder Signale gezielt umschaltet und verteilt.

🎛️ Knob 🔘 Button 🔼 Up/Down Button 🔀 Input-Switch 🎯 Input-Multiplexer 🔀 Output Switch 🎯 Output Multiplexer 🔢 Const

🎛️ Knob (knob)

What it's for

A physical-style knob you turn by hand (with the mouse, or a real hardware knob if your board has one wired up) to send out a CV value — the digital equivalent of a potentiometer on a Eurorack panel. Use it for anything you want to control live and manually: filter cutoff, an effect mix, a volume, or a modulation amount.

Input

Layer — a CV that switches between the knob's stored "layers" (see Knob Settings), letting one physical knob recall different saved positions.

Outputs

Each knob position on the panel has its own voltage output (labeled 1.1, 1.2, … and so on per layer) — patch whichever knob's output you need into the parameter you want to control.

🔘 Button (button)

What it's for

An on-screen (or hardware) push button that sends out a value when pressed — use it as a manual gate/trigger source, a mute switch, or anything else you'd want to fire by hand instead of patching it from elsewhere.

Input

Layer — a CV that switches between the button's stored layers, so one physical button can recall different behaviors.

Outputs

Each button has its own output per layer — patch it into a Gate input, a Mute, or any other on/off-style parameter.

🔼 Up/Down Button (up-down-button)

What it's for

A pair of increment/decrement buttons that step a value up or down — handy for things like paging through patterns, nudging a CV in fixed steps, or building a simple on-screen counter.

Output

Out — the current stepped value as CV.

🔀 Input-Switch (switch)

What it's for

An Input-Switch (a CV selector with two inputs) — lets you flip between two different signals and send only the selected one onward, like an A/B switch on a pedalboard.

Inputs

  • In 1 / In 2 — the two candidate signals.

Output

Out — whichever of In 1 / In 2 is currently selected (toggle it from the widget itself, or patch a CV to switch it automatically).

🎯 Input-Multiplexer (multiplexer)

What it's for

An Input-Multiplexer — like the Input-Switch but with up to 16 inputs instead of just two. Great for switching between many CV or audio sources and routing only the chosen one downstream, e.g. picking which of several oscillators currently feeds your filter.

Inputs

  • Select — picks which input is currently passed through.
  • In 1…In n — the candidate signals (add more from the widget's settings, up to 16).

Output

Out — the currently-selected input, passed straight through.

🔀 Output Switch (output-switch)

What it's for

The mirror image of Input-Switch: one incoming signal, routed to one of two possible destinations. Use it to send a single source to either of two places depending on a switch — for example, alternating a signal between two different effects chains.

Input

In — the signal to route.

Outputs

Out 1 / Out 2 — only one carries the signal at a time, depending on which is selected.

🎯 Output Multiplexer (output-multiplexer)

What it's for

Like Output Switch, but with up to 16 possible destinations instead of two — one input signal, routed to whichever one of many outputs you select. Useful for sending a single source around to different parts of a big patch one at a time.

Inputs

  • In — the signal to route.
  • Select — picks which output currently receives it.

Outputs

Out 1…Out n — only the selected one carries the signal (add more from the widget's settings, up to 16).

🔢 Const (const)

What it's for

Outputs a fixed, unchanging value — a constant CV. Use it to feed a steady offset, a fixed pitch transpose, or any parameter you want locked to one value rather than modulated.

Output

The widget's single output — the constant value you set on the widget itself.
