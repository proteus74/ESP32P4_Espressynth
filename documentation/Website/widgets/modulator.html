Modulator

Widgets, die sich über die Zeit verändern und damit andere Parameter steuern: LFOs, Hüllkurven, eine Wavetable-Engine, Step-Sequenzer, ein Drum-Sequenzer, Sample & Hold und mehr. Das Herzstück für Bewegung und Ausdruck im Patch.

🔄 LFO (lfo)

What it's for

A Low Frequency Oscillator — a slow, repeating wave used to wobble other things over time rather than to make an audible tone itself. Patch it into a filter's cutoff for a wah-wah sweep, into pitch for vibrato, into amplitude for tremolo, or anywhere else you want automatic, cyclic movement. For self-drawn, morphable shapes use the Wavetable widget instead.

Inputs

  • Rate — how fast it cycles. Double-click the widget to set the maximum rate the 0–10 V range maps to.
  • Phase — where in its cycle it starts.
  • Reset — a trigger input that restarts the cycle from the beginning, handy for syncing the wobble to a new note.
  • One Shot — makes the LFO run through its shape once instead of looping.
  • Global — lets all voices share one LFO instead of each voice running its own.
  • Offset — shifts the wave up or down so it isn't centered on zero.
  • Gain — how big the wobble is (0–10 V swing).

Output

Out — the wobbling CV signal. Patch it wherever you want that slow movement.

∿ Wavetable (wavetable)

What it's for

A modulator like the LFO, but its waveform is a wavetable: a row of up to 16 self-drawn single-cycle shapes of 128 steps each that the Morph control blends between. Between the steps the value is interpolated, so even a very slow cycle glides smoothly instead of stepping. Use it for movements no fixed LFO shape can give you — stepped patterns, lopsided swells, or shapes that slowly change character while they play.

Inputs

  • Rate — how fast it cycles. Double-click the widget to set the maximum rate the 0–10 V range maps to.
  • Morph — the position in the wavetable: 0 V = first slot, 10 V = last slot, in between the neighbouring slots are crossfaded. Patch an LFO or an envelope in to sweep through the table automatically.
  • Reset — a trigger input that restarts the cycle from the beginning, handy for syncing to a new note.
  • One Shot — runs through the shape once per reset instead of looping.
  • Global — lets all voices share one wavetable modulator instead of each voice running its own.
  • Gain — how big the swing is (0–10 V).

Preview and editor

The small preview shows the waveform at the current morph position, with a line marking where in the cycle it currently is. Click it or Edit to open the editor:

  • Slots — the bar at the top holds the waveforms in morph order. + adds a copy of the selected slot, − removes it.
  • Presets — Sine, Saw, Square and Triangle fill the selected slot as a starting point.
  • Freehand — draw the waveform directly with the mouse, pen or finger.
  • Harmonics — build the slot additively: each bar is the level of one harmonic (above the line positive, below inverted).
  • Cycle — how long one pass through the 128 steps takes, in seconds (the time axis under the drawing shows it). This sets the widget's Rate (Rate = 1 / Cycle); turning Rate down later simply stretches the same shape and interpolates between the steps.
  • Snap to Zero — cuts the waveform at the zero crossings nearest to its start and end and stretches it back to full length, so the loop point doesn't click. While switched on it is re-applied after every edit.

Everything you draw is audible right away — in the browser preview and on the device — even before you press Apply. Apply keeps the new table, Cancel brings the previous one back. The table is stored permanently when you save the preset — until then it is only in the running sound.

Output

Out — the modulation CV signal (0 V up to the Gain setting).

⛰️ ADSR (adsr)

What it's for

The classic Attack/Decay/Sustain/Release envelope generator. It turns a simple on/off Gate (a held key) into a shaped rise-and-fall CV curve, which is what actually gives a note its shape — a pluck, a swell, a pad, a stab.

Inputs

  • Gate — high while the note is held, low when released. Patch this from Midi-In's Gate.
  • Velocity — can scale how strongly the envelope responds to how hard the note was played.
  • Attack — how long it takes to rise to full level when the gate turns on.
  • Decay — how long it takes to fall from the peak down to the sustain level.
  • Sustain — the level it holds at while the key stays down.
  • Release — how long it takes to fade to zero after the key is let go.

Output

Out — the shaped envelope CV. Patch it into an oscillator's Amplitude, a filter's Cutoff, a Gain/VCA, or anywhere you want a note-shaped rise and fall.

⌁ DX Envelope (dx-envelope)

What it's for

A four-stage rate/level envelope in the style of classic DX-series FM synths — more flexible than a standard ADSR because each of its four segments has its own independent level and time, so you can build multi-stage shapes (slow swells, double-hump attacks, plucky-then-swelling pads) that a simple ADSR can't do.

Inputs

  • Gate — starts the envelope running; patch from Midi-In's Gate.
  • Velocity — can scale the envelope's response to playing strength.
  • Level 1–4 / Time 1–4 — four target levels and the time it takes to reach each one, played back in order. Think of it as drawing the envelope's shape as four connected line segments.

Output

Out — the resulting envelope CV, patch it anywhere an ADSR could go.

↔️ DeTune (detune)

What it's for

A small utility that shifts a pitch CV up or down by a controllable amount — useful for detuning a second oscillator slightly against a first for a thicker, chorused unison sound, or for transposing a CV by a fixed interval.

Inputs

  • In — the incoming pitch CV to shift.
  • Amount — how far, and in which direction, to shift it.

Output

Out — the shifted pitch CV. Patch it into a second oscillator's Pitch input alongside your original pitch source for a unison/detune effect.

⏱️ Clock (clock)

What it's for

Sends out a steady stream of timing pulses, synced to ESPRESSYNTH's single master tempo (set from the tab bar's Master Clock). Use it to drive sequencers, arpeggiators, clocked LFOs, or anything else that needs to stay in time with your song.

Outputs

  • Pulse — a trigger that fires on every clock step, patch into a Step Arpeggiator's or Drum Sequencer's Clock input.
  • Frequency — the clock's current tempo expressed as a CV, in case you want to react to tempo elsewhere in the patch.

This widget owns only its own pulse width — the tempo itself comes from the shared Master Clock, so every Clock widget in your patch stays in sync.

▦ Step Arpeggiator (step-arpeggiator)

What it's for

A monophonic step sequencer/arpeggiator — sixteen knobs, each defining a pitch step, played back one after another as a clock pulses it forward. Great for classic arpeggio and sequenced-bassline patterns without needing a DAW.

Inputs

  • Clock — advances to the next step on each pulse (patch from a Clock widget, or leave unpatched to use the internal Rate).
  • Gate — gates the sequencer on/off, e.g. from a held key.
  • Pitch — an optional pitch CV added on top of the steps, useful for transposing the whole pattern by playing a key.
  • Direction — picks Forward, Backward, Ping-Pong, or Random playback order.
  • Gate Out Time — how long each step's gate output stays high.
  • Rate — the built-in fallback clock speed, used only when nothing is patched into Clock.
  • Step 1–16 — the pitch value for each of the sixteen steps.

Outputs

  • CV — the current step's pitch, patch into an oscillator's Pitch.
  • Gate Out — a gate pulse for each step, patch into an ADSR's Gate to re-shape each note.

▦ Drum Sequencer (drum-sequencer)

What it's for

An 8-track step sequencer for rhythm — a classic drum-machine-style grid where each of the eight tracks fires its own trigger, so you can pattern out kick, snare, hats, and more, each driving its own drum or percussion sound.

Inputs

  • Clock — advances the pattern one step per pulse (patch from a Clock widget, or fall back to Rate).
  • Gate — starts/stops the whole sequencer.
  • Pattern — selects which saved pattern is currently playing.
  • Rate — the built-in fallback clock speed when Clock is unpatched.
  • Switch @ End — automatically jumps to another pattern once the current one finishes, for building song-style arrangements.

Outputs

For each of the eight tracks: T1–T8 (a trigger pulse when that track's step fires — patch into a drum voice's Gate) and V1–V8 (that step's velocity as CV, for hit-to-hit dynamics).

⌁ S&H (sample-hold)

What it's for

Sample & Hold "freezes" whatever value is at its input the instant it receives a trigger, and holds that frozen value steady until the next trigger. Classic use: feed it random noise or a fast LFO and trigger it from a clock for stepped random-CV sequences (bloopy sci-fi arpeggios, random filter sweeps).

Inputs

  • In — the signal to sample.
  • Trigger — grabs a fresh sample of In the moment this crosses the threshold. Patch a Clock's Pulse here for evenly-spaced steps.
  • Threshold — the trigger level that counts as "fire".

Output

Out — the held (frozen) CV value, steady until the next trigger.

⁘ Burst Gen (burst-generator)

What it's for

Turns one incoming trigger into a repeated burst of triggers (a roll/ratchet), or delays a single trigger before it fires — useful for drum rolls, ratcheted arpeggios, or simply pushing a gate a little later in time.

Inputs

  • In — the trigger/gate to react to.
  • Mode — chooses burst-repeat vs. single-delay behavior.
  • Count — how many repeats to fire in burst mode.
  • Time — the spacing between repeats, or the delay length in delay mode.
  • Decay — fades the velocity/level of each successive repeat, for a natural-sounding roll.

Output

Out — the resulting trigger/gate stream, patch into a drum voice's Gate or anywhere else that wants a rhythmic pulse.
