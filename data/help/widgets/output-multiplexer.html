What it's for

Like Output Switch, but with up to 16 possible destinations instead of two — one input signal, routed to whichever one of many outputs you select. Useful for sending a single source around to different parts of a big patch one at a time.

Inputs

  • In — the signal to route.
  • Select — picks which output currently receives it.

Outputs

Out 1…Out n — only the selected one carries the signal (add more from the widget's settings, up to 16).
