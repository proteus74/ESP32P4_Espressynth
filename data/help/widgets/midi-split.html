What it's for

Midi-Split takes one incoming MIDI stream and fans it out so different parts of it can go to different destinations — for example, sending each MIDI channel to its own Midi-In or sound-generating widget, so you can layer or multitimbrally control several instruments from one MIDI source.

Input

  • MIDI — the MIDI stream to split, usually patched from a Midi-In's MIDI output or another MIDI source.

Outputs

Open the widget to configure the splits — its output jacks are created for each one you set up, each carrying its own MIDI stream.
