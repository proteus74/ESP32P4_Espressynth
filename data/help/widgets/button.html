What it's for

An on-screen (or MIDI CC / note bound) push button that sends out a value when pressed — use it as a manual gate/trigger source, a mute switch, or anything else you'd want to fire by hand instead of patching it from elsewhere.

Input

Layer — a CV that switches between the button's stored layers, so one physical button can recall different behaviors.

Outputs

Each button has its own output per layer — patch it into a Gate input, a Mute, or any other on/off-style parameter.
