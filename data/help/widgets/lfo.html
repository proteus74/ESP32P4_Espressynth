What it's for

A Low Frequency Oscillator — a slow, repeating wave used to wobble other things over time rather than to make an audible tone itself. Patch it into a filter's cutoff for a wah-wah sweep, into pitch for vibrato, into amplitude for tremolo, or anywhere else you want automatic, cyclic movement.

Inputs

  • Rate — how fast it cycles.
  • Amplitude — how big the wobble is.
  • Phase — where in its cycle it starts.
  • Reset — a trigger input that restarts the cycle from the beginning, handy for syncing the wobble to a new note.
  • One Shot — makes the LFO run through its shape once instead of looping.
  • Global — lets several LFO widgets share one free-running clock instead of each running independently.
  • Offset — shifts the wave up or down so it isn't centered on zero.

Output

Out — the wobbling CV signal. Patch it wherever you want that slow movement.
