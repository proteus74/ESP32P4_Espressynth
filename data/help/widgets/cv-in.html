What it's for

Reads a real control-voltage signal coming into ESPRESSYNTH's hardware CV input jacks — this is the bridge between your actual modular gear (or any external CV/gate source) and the widgets inside this software patch. Pick which physical port/address/channel to read from in the widget's settings.

Output

Value — the incoming hardware voltage, turned into a CV signal you can patch into any widget on the canvas — an oscillator's pitch, a filter cutoff, an envelope's gate, anything.
