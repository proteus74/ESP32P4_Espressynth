What it's for

FM8 is a complete 8-operator FM synthesizer voice in a single widget: eight sine operators, a modulation matrix (any operator can modulate any other, including itself), a DX7-style envelope per operator and one audio output. Because everything lives in one widget it needs far less memory than building the same sound from eight oscillators and eight envelopes.

Editing and loading DX7 SysEx

Double-click the widget (or right-click it) to open the patch editor. Load a DX7 .syx file - a single voice or a 32-voice bank - pick a voice from the list and the algorithm, operator ratios, levels, envelopes, velocity/keyboard scaling and feedback are applied immediately. The DX7's LFO and pitch EG are not imported.

Inputs

  • Pitch - pitch CV, normally Midi-In's Pitch.
  • Gate - note on/off, normally Midi-In's Gate.
  • Velocity - note velocity, normally Midi-In's Velocity.
  • Tune - global pitch offset (1 V per octave around 5 V).
  • Gain - output level.

Operators

Per operator: ratio (coarse/fine) or fixed frequency, detune in cents, output level 0-99, velocity sensitivity, rate scaling, keyboard level scaling, a four-stage envelope (R1-R4 rates, L1-L4 levels, exactly as on the DX7: L1-L3 are reached while the key is held, L4 on release) and feedback with a selectable source operator. Levels use the DX7's logarithmic scale (0.75 dB per step).

Matrix

Row = operator that is modulated, column = modulating operator, value 0-1. The Out column of the operator table is each operator's weight in the audio output (the carriers).

Output

Out - the voice's audio, polyphonic like every voiced widget (set the voice count on Midi-In).
